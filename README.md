### Setup Instructions

1. **Install:** `npm install`
2. **Setup:** `cp .env.example .env.local`
3. **Run:** `npm run dev`
4. **Local URL:** http://localhost:3000
5. **Login:** `admin@gmail.com` / `Password#0000`
